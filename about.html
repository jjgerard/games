Learning GamesGames

About

These are small browser games for learning statistics and R. They grew out of two earlier games, Shapes and Trial and Error, which teach by letting you try things and see what happens. The same idea is applied here to topics that are usually taught with equations or with code you have to type.

Why they exist

The games start with very basic ideas. The first screen of the Bayes game asks you to pull one shape out of a bag. Every later idea is built from the one before. If you already know the basics, a short placement test takes you past them.

How they teach

  • Meet the idea before the name. You build a belief, a likelihood or a join first. The word comes after, in the explanation.
  • One possible move. The first level of anything new has a single flashing control, so you never wonder what to do.
  • Visual answers. You drag, tap and place. Some levels use short text choices.
  • Checking. Answer keys are checked against R. Questions are generated and tested so that a fixed strategy, such as always picking 50/50, does not pass.
  • Common mistakes. Levels are aimed at places where learners often get stuck, such as which scale a number is on, what an intercept means, or what a grouped table looks like after summarising.

Accessibility

Text is never smaller than the question text. Buttons are at least 44 pixels square. Colours meet WCAG contrast. Pictures have text alternatives, dialogs trap focus and close on Escape, and everything works with a keyboard. Each game has an automated audit that checks this on three phone sizes. If something is hard to use, please say so.

Sources

The Bayesian game follows the order of Nicenboim, Schad and Vasishth, An Introduction to Bayesian Data Analysis for Cognitive Science, but the examples and wording are original. The R game follows an introductory R course. The model game is based on common problems in reading mixed-effects model output.

Privacy, licence, source

There are no accounts, no tracking and no server. Progress is saved in your browser only, and "Erase progress" in the menu removes it. The code is released under the MIT licence, so you can copy and adapt it. The source is at github.com/jjgerard/games.
